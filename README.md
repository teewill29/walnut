# Mockups

The approved screens, as the source files from the design canvas:

| File | Screen |
|---|---|
| `Main.dc.html` | Play, desktop |
| `Phone.dc.html` | Play, phone (390×844) |
| `Review.dc.html` | Post-game review, desktop |
| `History.dc.html` | History and progress, desktop |

They're HTML with inline styles, plus a small logic class at the bottom that builds the board and the sample data. Treat them as visual reference: copy the layout, spacing, colors and type; don't import them. They don't run on their own (they expect the canvas runtime's `support.js`).

To see them rendered: https://claude.ai/artifact/LNBa9dUfVsSKzeeJJXSmKf

The sample data in them is made up. The pieces are font glyphs standing in for the real wood pieces (DESIGN.md → Pieces).
